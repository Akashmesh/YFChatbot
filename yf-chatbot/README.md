# YF Chatbot App

This folder contains the React + Vite application for YF Chatbot.

For the full project overview, setup steps from the repository root, and customization notes, see the repository-level `README.md`.

## Quick Start

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`

## Main Files

- `src/App.jsx` contains the chatbot flow logic
- `src/data/messages.json` stores the menu text and response links
- `src/style.css` contains the main UI styling
